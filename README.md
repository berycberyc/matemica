# matemica

Адаптивная диагностика по математике для подготовки к НИШ, БИЛ и РФМШ.

## Как это устроено

- `src/lib/engine.ts` — движок ветвления: подъём по уровням внутри темы,
  спуск по карте зависимостей. Ни экранов, ни сети — только логика.
- `src/lib/api.ts` — связь с базой Supabase, с постраничной тягой.
- `src/screens/` — главная страница, кабинет ученика, кабинет преподавателя.
- `src/components/` — клавиатура и общие элементы.
- `sql/` — схема базы, темы, банк задач, ученики.

## Правки

`npm run dev` — посмотреть у себя. `npm run build` — проверка типов и сборка.
Если сборка не проходит, GitHub не пустит правку на сайт.
